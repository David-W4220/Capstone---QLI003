# QLI003 Project Documentation

Documentation, design materials, and reference data for the QLI003 Inventory Management System.

## Folder Structure

```
docs/
├── design/              # UI/UX design materials
│   ├── wireframes/     # Initial hand-drawn wireframes
│   └── mockups/        # Refined UI mockups
├── reference-data/     # Source data and reference files
└── vendor-info/        # Vendor contacts and purchase links
```

## Contents Overview

### design/
All UI/UX design work including initial wireframes and mockups that guided the application development.

**Wireframes** - Hand-drawn sketches showing:
- Dashboard layouts
- Form designs (checkout/checkin)
- Settings and admin views
- Login screen
- Navigation patterns
- Feature concepts

**Mockups** - Higher fidelity designs showing:
- Refined layouts
- Color schemes
- Component styling
- Interaction patterns

### reference-data/
Excel files containing the original inventory data and location labeling systems.

- Original OT Closet inventory spreadsheet
- Shelf/bin labeling system (A1, B1, C1, etc.)
- Used for initial database population

### vendor-info/
Vendor contact information and reorder links for purchasing equipment.

- 2025 vendor links document
- Purchase URLs and pricing
- Vendor contacts
- Reorder information
